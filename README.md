R scripts for the article Cervellini, De Benedictis et al. Training and intercalibration reduce observer-induced variability in forest vegetation surveys

## File description

- intercal.R: R script file with knitr::spin() compatibility
- intercal.pdf: pre-rendered notebook version of the script

## Data requirements

Data can be downloaded at <https://doi.org/10.5281/zenodo.18710554> and put in a "data" folder inside the working directory.
